EP11 · 认证授权

谁在敲门，就发给谁一把钥匙

认证授权就是「发 token」和「查 token 放行」两件事。Laravel 用 Sanctum 管 token、用 auth:sanctum 中间件护路由；FastAPI 用 OAuth2PasswordBearer 取 Bearer、用 Depends(get_current_user) 护路由。心智一样，落笔不同。

01

一句话心智模型

两边都是「登录发 token → 带 token 访问 → 中间件/依赖校验」三步走。Laravel 把它收进 Sanctum 包和路由中间件；FastAPI 把它拆成可组合的函数依赖。同一个心智，两种落笔。

Laravel 的认证
  • Sanctum 负责签发/存储 token
  • auth:sanctum 中间件校验 Bearer
  • 路由上加中间件即受保护
FastAPI 的认证
  • OAuth2PasswordBearer 从请求取 token
  • Depends(get_current_user) 校验并注入用户
  • 路由加依赖即受保护，可复用
一句话：Laravel 是「中间件」思维，FastAPI 是「依赖注入」思维。钥匙一样，看门人站的位置不同。
02

对照①发 token（登录）

登录成功后返回 access_token。两边结构完全一致。

Laravel 13 · PHP
// routes/api.php Route::post('/login', function () { return [ 'access_token' => 'fake-jwt', 'token_type' => 'bearer', ]; });
FastAPI 0.140 · Python
# fastapi/app/ep11.py · 教学 stub @router.post('/login') def login(form: OAuth2PasswordRequestForm = Depends()): # 演示账号 alice / secret return TokenOut( access_token=f'user:{form.username}')
这是教学 stub（token 形如 user:alice），不是生产 JWT。真实项目：Laravel 用 $user->createToken()；FastAPI 用 PyJWT / Authlib 签发。Swagger 的 Authorize 走这个表单登录。
03

对照②保护路由（查 token）

「这一组/这条要登录」——左用中间件护 /me，右用依赖护 /me。

Laravel 13 · PHP
// auth:sanctum 护 /me Route::middleware('auth:sanctum') ->get('/me', function () { return auth()->user(); });
FastAPI 0.140 · Python
# Depends 护 /me @router.get('/me') def me(u: dict = Depends(get_current_user)): return u
FastAPI 的「护路由」是路由级依赖（Depends），不是全局中间件。被依赖的函数里抛 401 即拒绝访问——等于中间件的 return 401。
04

对照③取 token 的依赖函数

FastAPI 把「读懂 token」抽成一个可复用函数：OAuth2PasswordBearer 先从请求抓 Bearer，get_current_user 再做校验。

Laravel 13 · PHP
// 由 auth:sanctum 隐式处理 // 控制器里直接取用户： auth()->user(); // 框架自动解析 Bearer token
FastAPI 0.140 · Python
# 显式取 + 校验 token oauth2 = OAuth2PasswordBearer( tokenUrl='/ep11/login') def get_current_user( token: str = Depends(oauth2)): if not token.startswith('user:'): raise HTTPException(401, detail='invalid token') username = token.removeprefix('user:') return {'user': username}
Laravel 把「取+校验用户」藏在 auth:sanctum 里；FastAPI 把它摊开成两个函数，更显式、更好单测。注意 tokenUrl 必须等于登录路径（坑 3）。
05

⚠️ Laravel 老手常见坑

坑 1 · 别把密钥硬编码：JWT 的 SECRET_KEY、Sanctum 的 APP_KEY 必须进 .env，别写死在代码里。提交到仓库等于交出门钥匙。
坑 2 · 生产别用 stub token：演示约定 user:<name>，仅教学。真实 FastAPI 用 JWT（PyJWT）签发/校验，Laravel 用 Sanctum 真实 token；否则任何人都能伪造身份。
坑 3 · tokenUrl 路径要一致：OAuth2PasswordBearer(tokenUrl=...) 必须和登录路由路径相同（本例 /ep11/login），否则 /docs 的 Authorize 按钮会 404，依赖也取不到 token。
06

三步，跑起来

terminal
~ ❯ uvicorn app.main:app --reload → 打开 http://127.0.0.1:8000/docs 1) POST /ep11/login → username=alice password=secret 2) 点 Authorize 填 Bearer token，或 Header: Authorization: Bearer user:alice 3) GET /ep11/me → 不带 token 得 401，带 token 才放行
把仓库里 fastapi/app/ep11.py 跑起来：登录用表单 alice/secret 拿 user:alice；/ep11/me 经 Depends(get_current_user) 校验。打开 /docs 点 Authorize 即可联调。
07

上手练习（10 分钟）

给 /ep11/me 加一个「仅 admin」的校验：当 token 不等于 admin-jwt 时返回 403。

FastAPI · 你的练习
# 改 get_current_user： def get_current_user( token: str = Depends(oauth2)): if token != 'admin-jwt': raise HTTPException( status.HTTP_403_FORBIDDEN, detail='forbidden') return {'user': token}
做完你会发现：权限控制只是依赖函数里多一个判断，和 Laravel 在中间件/Policy 里写 if (!$user->isAdmin()) abort(403) 完全同构。难点不在语法，在「把校验放哪一层」。
