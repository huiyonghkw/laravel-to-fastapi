EP10 · 中间件

请求路上的那道关卡

中间件就是「请求进处理函数之前 / 响应出之前」统一插进去的一段逻辑：记日志、鉴权、加 CORS 头。两边心智一样；差别是落点——Laravel 写中间件类 + Kernel 注册，FastAPI 路由级用 Depends、全局用 add_middleware。

01

一句话心智模型

无论是 Laravel 的 Middleware 还是 FastAPI 的 Depends / add_middleware，本质都是「请求 → 前置逻辑 → 处理函数 → 后置逻辑」的管道。Laravel 把它收进 Kernel 和路由分组；FastAPI 把它拆成两层：路由级依赖 + 全局 ASGI 中间件。

Laravel 的中间件
  • 中间件是一个类，handle() 包裹请求
  • 注册在 app/Http/Kernel.php：全局 / 路由 / 分组
  • 分组用 Route::middleware('x')->group()
FastAPI 的中间件
  • 路由级「中间件」= Depends(...) 依赖（最常用）
  • 全局 ASGI 中间件用 app.add_middleware(...)
  • 分组用 APIRouter(dependencies=...)
一句话：Laravel 是一套中间件体系，FastAPI 是「依赖 + ASGI 中间件」两层。同一个管道心智，两种落笔。
02

对照路由级中间件

「某条路由进来先跑一段逻辑」——Laravel 用 Route::middleware('log')，FastAPI 用 dependencies=[Depends(log_request)]。同一个心智。

Laravel 13 · PHP
// routes/api.php // 需先注册 log 中间件 Route::middleware('log') ->get('/secure', fn () => ['ok' => true]);
FastAPI 0.140 · Python
# app/ep10.py def log_request(req: Request): return None # 放行；可 raise 拦截 @router.get('/secure', dependencies=[Depends(log_request)]) def secure(): return {'ok': True}
FastAPI 里 dependencies=[Depends(...)] 是路由级中间件：进处理函数前先跑 log_request，返回 None 即放行；想拦截直接 raise HTTPException。等于 Laravel Route::middleware('log')。
03

对照分组中间件 + 全局 CORS

「一组路由统一鉴权」用分组依赖；「所有响应加 CORS 头」用全局 ASGI 中间件——两层分清楚。

Laravel 13 · PHP
// 分组中间件 Route::middleware('auth:sanctum') ->prefix('posts') ->group(function () { ... }); // 全局 CORS 在 Kernel 的 // $middleware 数组里注册 // \Illuminate\Http\Middleware\HandleCors
FastAPI 0.140 · Python
# 分组依赖（=分组中间件） posts = APIRouter( prefix='/posts', dependencies=[Depends(get_current_user)]) # 全局 ASGI 中间件 CORS from fastapi.middleware.cors import CORSMiddleware app.add_middleware( CORSMiddleware, allow_origins=['*'], allow_methods=['*'], allow_headers=['*'])
关键区别：dependencies= 是路由级（只罩住这个 router 的路由）；add_middleware 是全局（包住整个 app 的每一请求）。CORS、日志这类对所有请求生效的逻辑走全局；鉴权这类只罩部分路由的走路由/分组依赖。
04

⚠️ Laravel 老手常见坑

坑 1 · dependencies= 不是全局：写在某个 APIRouter(dependencies=...) 里，只对该 router 的路由生效。想全站生效要用 app.add_middleware 或给主 router 也加依赖。
坑 2 · 中间件顺序：Laravel 按 Kernel 数组顺序跑；FastAPI 全局中间件按注册的反序包请求（先注册的在外层）。需要「先 CORS 再鉴权」要注意登记顺序。
坑 3 · 依赖函数返回值：路由级依赖 return None 是放行；若想往处理函数注入对象（如当前用户），就 return 那个对象，处理函数参数里声明同名类型即可拿到。
05

06

上手练习（10 分钟）

把 log_request 升级成「只放行带 x-token 头的请求」，缺失就 401：

FastAPI · 你的练习
# 在 ep10.py 里改 log_request： def log_request(req: Request): if not req.headers.get('x-token'): raise HTTPException(401, detail='missing token')
做完你会发现：路由级依赖拦截 = Laravel 中间件里 return response 提前返回。中间件心智没变，只是 FastAPI 用「抛异常」表达「不放行」。
