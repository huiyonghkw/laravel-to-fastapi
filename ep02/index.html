EP02 · 路由

URL 到代码的那张地图

路由就是「哪个 URL 交给哪段代码」。两边思路一模一样；差别只在写法：Laravel 用 Route:: 门面一句句声明，FastAPI 用装饰器把函数直接变成路由。本篇讲清分组、中间件、路径参数。

01

一句话心智模型

无论是 Route::get 还是 @app.get，本质都是「URL 模式 + HTTP 方法 → 一段处理函数」。Laravel 把它收进路由文件集中管理；FastAPI 把它贴在函数头上，函数即路由。

Laravel 的路由
  • 集中在 routes/api.php
  • Route::get/post/... 门面声明
  • 分组、前缀、中间件一套组合
FastAPI 的路由
  • 装饰器贴在函数上，函数即路由
  • @app.get(...) / @router.post(...)
  • 多个路由收进 APIRouter 再挂载
一句话：Laravel 是「路由表」思维，FastAPI 是「装饰函数」思维。同一个心智，两种落笔。
02

对照①单条路由

一条 GET、一条 POST，左右一一对应。

Laravel 13 · PHP
// routes/api.php Route::get('/health', function () { return ['ok' => true]; }); Route::post('/posts', [PostController::class, 'store']);
FastAPI 0.140 · Python
# ep02.py @router.get('/health') def health(): return {'ok': True} @router.post('/posts') def create_post(): return {'created': True}
Laravel 把处理函数写成闭包或指向 Controller；FastAPI 直接把函数本身当处理函数——没有「控制器」这层包装（对照见 EP03）。
03

对照②路径参数 + 类型校验

URL 里的变量，两边都会自动按类型转换/校验。FastAPI 靠类型提示，Laravel 靠路由参数（或隐式绑定）。

Laravel 13 · PHP
// {post_id} 是路由参数 Route::get('/posts/{post_id}', [PostController::class, 'show']); // 控制器里 public function show(int $post_id) { return ['post_id' => $post_id]; }
FastAPI 0.140 · Python
# {post_id}:int 自动转 int @posts.get('/{post_id}') def get_post(post_id: int): if post_id <= 0: raise HTTPException(404) return {'post_id': post_id}
FastAPI 里 post_id: int 既做转换又做校验：传非数字直接 422。Laravel 用路由模型绑定能更优雅（Post $post 直接拿到模型）。
04

对照③路由分组（前缀 + 标签）

一堆同前缀的路由，两边都能「打包成一组」。左 Laravel 用 prefix()->group()，右 FastAPI 用 APIRouter(prefix=)。

Laravel 13 · PHP
// 一组 /posts/* Route::prefix('posts')->group(function () { Route::get('/', [PostController::class,'index']); Route::post('/', [PostController::class,'store']); });
FastAPI 0.140 · Python
# 一个子 router 打包 posts = APIRouter(prefix='/posts', tags=['posts']) @posts.get('') def list_posts(): ... @posts.post('') def create_post(): ... router.include_router(posts) # 挂回主路由
tags=[...] 只是给 /docs 分组显示用；真正的「前缀」是 prefix。挂回主路由用 include_router——等于 Laravel 路由文件被框架自动加载。
05

对照④分组中间件（统一鉴权）

「这一组路由都要先登录」——Laravel 用 middleware()->group()，FastAPI 用 APIRouter(dependencies=...)。同一个心智。

Laravel 13 · PHP
// 一组路由加 auth 中间件 Route::middleware('auth:sanctum') ->prefix('posts') ->group(function () { ... });
FastAPI 0.140 · Python
# 一组路由加依赖（=中间件） posts = APIRouter( prefix='/posts', dependencies=[Depends(get_current_user)]) # 组内每个路由都先跑 get_current_user
注意区别：FastAPI 的「分组鉴权」是路由级依赖（dependencies=），不是全局 ASGI 中间件（那是 add_middleware，用于 CORS、日志这类全局逻辑）。
06

⚠️ Laravel 老手常见坑

坑 1 · 动态参数吃掉固定路由：/posts/{id} 会匹配 /posts/me。需要固定子路由（如 /posts/me）就写在参数路由之前，或换命名避免冲突。
坑 2 · 装饰器挂错 router：子路由要用 @posts.get(...) 而不是 @router.get(...)，否则前缀不生效；最后别忘了 router.include_router(posts)。
坑 3 · prefix 斜杠拼错：APIRouter(prefix='/posts') + @posts.get('') → /posts；若写成 @posts.get('/') 会变成 /posts/（带尾斜杠）。保持一处带 / 即可。
07

08

上手练习（10 分钟）

给 posts 加一个嵌套路由 GET /ep02/posts/{id}/comments：

FastAPI · 你的练习
# 在 ep02.py 的 posts 子 router 上加： @posts.get('/{post_id}/comments') def comments(post_id: int): return {'post_id': post_id, 'comments': []}
做完你会发现：嵌套路径只是把两段参数拼起来，和 Laravel Route::get('/posts/{id}/comments') 完全同构。难点不在语法，在「把路由收进哪个 router」的组织习惯。
