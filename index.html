做了 8 年 Laravel，
怎么上手 FastAPI

不从头学，把肌肉记忆平移过去。你是 Laravel 老手、Python 零基础——本系列不教你 Python，只把你的 Laravel 心智逐概念翻译成 FastAPI 写法，左 Laravel / 右 FastAPI，复制即跑。

这个系列是什么

2026 年，两个框架不约而同拥抱 AI：Laravel 13 出了官方 AI SDK，FastAPI 成了 LLM 后端的基础设施。向左学了这么多年，向右也该通了。

但很多人不是不会 Python，是不想从「print hello」重新来过。所以我们换个学法：不学新语言，只做概念平移——每期一个后端概念，左 Laravel、右 FastAPI，同框对照、可运行。

配套仓库里 fastapi/ 是复制即跑的对照骨架（uvicorn + /docs + pytest）；laravel/ 是源码对照（无完整 artisan 工程，见 laravel/README.md）。每个 EP 的代码都从那里来。

怎么跟着学

1
平移，不重学：把 Laravel 的概念直接映射到 FastAPI，不补 Python 基础课。
2
左 Laravel · 右 FastAPI：每期一张同框对照，复制即跑，看见对应关系就懂。
3
从能跑开始：克隆仓库，cd fastapi && pip install -r requirements.txt && uvicorn app.main:app --reload，先看 /docs。
本系列不发小红书，以 HTML 长文 + 可运行代码发布在 GitHub Pages。CI 会跑 pytest 与 Docker build。
