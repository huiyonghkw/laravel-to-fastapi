EP00 · 世界观与代码对照

做了 8 年 Laravel，
怎么上手 FastAPI

不从头学，把肌肉记忆平移过去。本篇把世界观落成代码——六个最常用的后端概念，左 Laravel / 右 FastAPI，复制即跑。

01

为什么做这套对照学

2026 年，两个框架不约而同地拥抱 AI：Laravel 13 出了官方 AI SDK，FastAPI 成了 LLM 后端的基础设施。向左学了这么多年，向右也该通了。

但很多人不是不会 Python，是不想从「print hello」重新来过。所以我们换个学法：不学新语言，只做概念平移——你已有的路由、控制器、ORM、中间件、依赖注入，FastAPI 全都有对应物。

配套仓库 fastapi/ 与 laravel/ 是可运行的对照代码骨架。下面每段代码都来自那里，建议边读边抄、边抄边跑。
02

两个框架怎么定位

Laravel 13 · 全栈
  • 精装全栈房：路由、ORM、队列、认证、迁移一个 composer 装齐
  • 请求走 PHP-FPM，同步阻塞
  • 哲学：全栈 MVC、约定优于配置
FastAPI 0.140 · API
  • API 专用毛坯：只把请求变成 JSON，其余你自己选型
  • 请求走 ASGI 事件循环，异步并发
  • 哲学：API 优先、显式类型提示
最大的体感差在同步 vs 异步：Laravel 一个请求占满一个进程；FastAPI 一个进程能同时接很多——所以它在 AI 流式响应上更顺。
03

六个概念代码对照

下面每段都是左 Laravel / 右 FastAPI。先扫一眼「长得像不像」，再往下读差异点。代码已尽量精简，复制即可运行。

→ EP02 ① 路由（分组 + 中间件）

Laravel 13 · PHP
// routes/api.php Route::middleware('auth:sanctum')->group(function () { Route::get('/posts', [PostController::class, 'index']); Route::post('/posts', [PostController::class, 'store']); });
FastAPI 0.140 · Python
# 路由即装饰器 @app.get('/posts') def list_posts(): return {...} # 分组用 APIRouter router = APIRouter( dependencies=[Depends(get_current_user)])
Laravel 用 Route:: 门面 + 闭包分组；FastAPI 用 @app.get 装饰器，多组路由收敛到 APIRouter 再 include_router。语义一一对应。

→ EP03 ② 控制器 vs 路径操作函数

Laravel 13 · PHP
// PostController.php class PostController extends Controller { public function index() { return Post::all(); } }
FastAPI 0.140 · Python
# 路由即函数，无需 Controller 类 @router.get('/posts') def list_posts(): return db.execute(select(Post)).scalars().all()
Laravel 把逻辑收进 Controller 类；FastAPI 直接把函数当一个「路径操作」。小项目更轻，大项目可把函数收进模块分组管理。

→ EP05 ③ 请求校验（Pydantic vs Form Request）

Laravel 13 · PHP
// StorePostRequest.php public function rules(): array { return [ 'title' => 'required|string|max:255', 'body' => 'nullable|string', ]; } // 控制器里直接用 public function store(StorePostRequest $req) { Post::create($req->validated()); }
FastAPI 0.140 · Python
# 一个 model 兼任 校验+序列化+文档 class PostCreate(BaseModel): title: str = Field(max_length=255) body: str | None = None @router.post('/posts') def create_post(p: PostCreate): return create_post_in_db(p)
这是最值得记住的一对：Laravel 要 Form Request（规则）+ Resource（序列化）两样；FastAPI 一个 Pydantic model 三件事全包，还顺手生成 Swagger 文档。

→ EP01/09 ④ 依赖注入（容器 vs Depends）

Laravel 13 · PHP
// 容器自动解析构造里的类型提示 public function __construct( private PostRepository $posts ) {} // $posts 由服务容器注入
FastAPI 0.140 · Python
# Depends 就是依赖注入 def get_db(): db = SessionLocal() try: yield db finally: db.close() @router.get('/posts') def list_posts(db = Depends(get_db)): return db.execute(select(Post)).scalars().all()
两者同构：都在「调用方」声明要什么，由框架把实例送进来。yield 还能管连接的生命周期——请求结束自动 close。

→ EP06 ⑤ ORM（Eloquent vs SQLAlchemy 2.0）

Laravel 13 · PHP
// Eloquent：模型即表 class Post extends Model { protected $fillable = ['title', 'body']; } // 用法 Post::where('user_id', $id) ->with('comments')->get();
FastAPI 0.140 · Python
# SQLAlchemy 2.0 风格 class Post(Base): id: Mapped[int] = mapped_column( primary_key=True) title: Mapped[str] # 用法（async） stmt = select(Post).where(Post.user_id == uid) await db.scalars(stmt)
Eloquent 开箱即用、约定多；SQLAlchemy 更显式、更贴近 SQL，也需要你自己接迁移（Alembic）。偏好「少写配置」选 Eloquent 思路，偏好「完全可控」选 SQLAlchemy。

→ EP11 ⑥ 认证（Sanctum vs fastapi.security）

Laravel 13 · PHP
// Sanctum 发 token $token = $user->createToken('api') ->plainTextToken; // 保护路由 Route::get('/me', fn() => auth()->user()) ->middleware('auth:sanctum');
FastAPI 0.140 · Python
# OAuth2 密码流 oauth2 = OAuth2PasswordBearer(tokenUrl='login') def get_current_user(t: str = Depends(oauth2)): return decode_token(t) @app.get('/me') def me(u = Depends(get_current_user)): return u
Laravel 用 Sanctum 帮你管 token 与中间件；FastAPI 用 fastapi.security 这套标准件，自己把 Depends 串起来。底层都是「Bearer Token → 解析 → 注入当前用户」。

05

三步，跑起来

terminal
~ ❯ cd fastapi && pip install -r requirements.txt ~ ❯ uvicorn app.main:app --reload → 打开 http://127.0.0.1:8000/docs Swagger 自动生成，Laravel 没这待遇
先把 /docs 打开看一眼——自动生成的接口文档，是 FastAPI 给新人的第一份礼物。Laravel 侧是源码对照（无完整 artisan 工程），阅读 laravel/routes/api.php 即可；要真跑请见 laravel/README.md。
05b

上手练习（10 分钟）

确认 FastAPI 侧真的跑起来了：打开 /docs，试打 GET /ep00/hello，看到 framework: FastAPI 即过关。

terminal
fastapi ❯ uvicorn app.main:app --reload ~ ❯ curl -s localhost:8000/ep00/hello | python -m json.tool → {"framework": "FastAPI", ...} 加分：pytest 跑通（fastapi/ 目录下直接 pytest）
Laravel 侧本仓是源码对照（见 laravel/README.md），不必 composer install 也能对照阅读。FastAPI 侧才是复制即跑。
