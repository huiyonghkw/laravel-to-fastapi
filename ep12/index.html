EP12 · 测试

让代码自己证明自己

测试就是「用一段程序去请求接口、再断言结果」。Laravel 用 Pest/PHPUnit 的内置 HTTP 测试；FastAPI 用 pytest + TestClient（基于 httpx）。本篇把三种典型断言一一对照，看完就能给项目加测试。

01

一句话心智模型

两边测试的本质一样：构造一个「假的」请求发到应用，再对响应做断言。Laravel 把请求伪装进框架内部（$this->get()）；FastAPI 用 TestClient 套一层 httpx，对 app 对象发真实 HTTP 语义的请求——但不真正起端口、不发网络。

Laravel 的测试
  • 测试继承 TestCase（PHPUnit）
  • $this->get()/post() 伪装请求
  • assertOk()/assertJson()/assertStatus() 断言
FastAPI 的测试
  • pytest 函数即用例
  • TestClient(app) 当浏览器发请求
  • r.status_code/r.json() + assert 断言
一句话：Laravel 是「框架内置 HTTP 测试」，FastAPI 是「pytest + TestClient 套 httpx」。同一个心智，两种落笔。
02

对照①最简单：GET 断言 200 + JSON

请求一个公开端点，断言状态码 200、且返回的 JSON 字段符合预期。左右一一对应。

Laravel 13 · Pest
// tests/Feature/HelloTest.php test('hello 返回 200', function () { $this->get('/api/hello') ->assertOk() ->assertJson([ 'framework' => 'Laravel', ]); });
FastAPI 0.140 · pytest
# fastapi/tests/test_ep12.py def test_hello(): r = client.get("/ep00/hello") assert r.status_code == 200 assert r.json()["framework"] == "FastAPI"
Laravel 用链式断言 ->assertOk()->assertJson()；FastAPI 用 Python 原生 assert 直接比对。assertJson 是宽松匹配（只校验给定键），r.json()["framework"] 是精确取值。
03

对照②校验失败：断言 422

POST 一个缺字段的 body，两边都应拿到 422（校验未通过）。对照 EP05 的 Pydantic / Form Request。

Laravel 13 · Pest
// 缺 email → 422 test('缺字段返回 422', function () { $this->post('/users', []) ->assertStatus(422); });
FastAPI 0.140 · pytest
# 缺 email → 422 def test_validate(): r = client.post("/ep05/users", json={"name": "a"}) assert r.status_code == 422
Laravel 端点是 POST /api/users（api.php 里路由被 RouteServiceProvider 自动加 /api 前缀）；FastAPI 是 POST /ep05/users。两边校验失败都返回 422，断言写法同构。
04

对照③容器/依赖注入端点

一个走容器或 Depends 注入的端点（对照 EP09），断言它真的返回了注入后拼出的结果。

Laravel 13 · Pest
// 容器解析链注入的端点 test('db-url 走容器注入', function () { $this->get('/db-url') ->assertOk() ->assertJsonPath('url', fn ($v) => str_starts_with($v, 'db://')); });
FastAPI 0.140 · pytest
# Depends 注入的端点 def test_di_nested(): r = client.get("/ep09/db-url") assert r.status_code == 200 assert r.json()["url"].startswith("db://")
依赖注入在测试里自动生效——你不需要为测试手动装配容器/FastAPI 的 Depends 链，直接请求即可。Laravel 用 assertJsonPath + 闭包断言；FastAPI 用 str.startswith()。
05

⚠️ Laravel 老手常见坑

坑 1 · 测试不是真进程，但要保证独立：每个用例应互不污染。Laravel 用 RefreshDatabase 事务回滚；FastAPI 用 pytest fixture 重建 TestClient / 独立 DB。别让一个测试的副作用泄漏到下一个。
坑 2 · TestClient 不发真实网络：TestClient(app) 在进程内直接调 ASGI app，不经过 TCP 端口，也不触发中间件栈之外的真实 HTTP。想测真实端口要用 httpx 另起服务，别误以为 TestClient 真发了请求。
坑 3 · 环境与配置隔离：测试要跑在独立环境（.env.testing / PYTHONPATH + conftest.py），避免误连生产 DB。FastAPI 侧注意 from app.main import app 的路径，跑测试时要在仓库根目录或正确设置 PYTHONPATH。

07

上手练习（10 分钟）

给 /ep00/hello 加一个「只断言 200」的极简测试（Laravel 侧对应 /api/hello）：

FastAPI · 你的练习
# 在 test_ep12.py 里加： def test_hello_status_only(): r = client.get("/ep00/hello") assert r.status_code == 200
Laravel 侧同理：test('hello 200', fn () => $this->get('/api/hello')->assertOk());。做完你会发现：测试就是「发请求 + 断言」，和写业务代码完全不同——它只负责验证，不动手改东西。
